# privilege-logging-lab

Tester-tier standalone app (port 7801): drives each Privilege gateway use case and scores what gets logged against the customer's four-clause audit requirement (user, agent, tool, policy decision). Mock replays 17 transactions measured 2026-11-07; Real is owner-run. Honesty is the product: gaps are shown, anything unmeasured is UNVERIFIED.

- Run: `./scripts/run.sh` (http://127.0.0.1:7801/) or `HOST_PORT=7801 docker compose up --build -d` (OrbStack). Test: `npm test` (server = `node --test test/*.test.js`, a glob; web = vitest against the real server in a child process; repo tests = `node --test scripts/*.test.mjs`). Preflight: `npm run doctor`. Reset: `npm run reset`. Browser proof: `node scripts/e2e.mjs all`. Regenerate derived files after touching data: `npm run talk-track`, `npm run diagrams`, `npm run content-pack` (tests fail on drift).
- Flow: `POST /api/run` = phase 1 (send in Real, look up the recording in Mock; no `waitMs` any more), `POST /api/fetch-log {caseId, restart?}` = ONE retrieval attempt; the page repeats it about once a second (`/api/info.retrieval` has intervalMs, maxMs 15 s, fallbackMs 4 s) until `retrieval.state` is `found`, `timeout`, `unreachable` or `not_configured`. Runs are stored per source.
- Core: `server/src/capture.js` (strict validator of `server/data/capture.json`, never edit its meaning), `scorer.js` (pure; lines in, met/partial/missing out; `ctx.na` from the use case), `lab.js` (mock replay, real run, Markdown table), `mcpRunner.js` (initialize, initialized, call; Mcp-Session-Id; traceparent per hop), `matcher.js` (pure: marker first, then the call window; window matches are `inferred`; other-app lines and untimed lines never window-match), `logSources.js` (kubectl-proxy pod log with `timestamps=true`, selector listing, search), `redact.js` (tokens/JWTs/keys/passwords masked before any line is scored or shown), `searchClient.js` (ES-style `_search`), `realClient.js` (the ONLY code that sends: origin pin, SSRF guard, no redirects, caps, key redaction), `netguard.js` (zero outbound; Real allow-list = the two configured hosts), `config.js` (settings from `~/Development/.env` / `STANDALONE_ENV`), `app.js` (API).
- Rules that bite: loopback bind only; one port, 7801 (`127.0.0.1:` only, a test pins it); `POST /api/mode` is exactly `{ source: "mock"|"real" }` (409 + reason when Real is not configured); the agent key is WRITE-ONLY (never in any API answer, never logged, `Bearer ***` in raw hops; a test greps every answer); Mock makes zero outbound attempts (test with a configured fake gateway that must see nothing); Real asks for a per-tab confirmation of the origins before the first send (412 until then); only `.example`/`.invalid` hosts; no real tenant, key or customer identifier anywhere; runs are kept per source so Mock and Real never mix.
- Real-only cases (`server/data/real-only-cases.json`, `realOnly: true`, groups Keys / Federated identity / Approvals / Registry lifecycle) have NO outcome, lines or score (the validator rejects any); `capture.cases` is the 17 measured ones, `capture.realOnly` the rest. Mock: Run disabled, `POST /api/run` 409 `real_only`, Scorecard "not measured". Per-case credentials: write-only field (`POST /api/bearer`, in memory per tab) or `PRIV_LOG_BEARER_<CASEID>`; never returned, redacted. Console-action cases send nothing (`Look for entries since`). `fed-valid-token` is minted by the lab when `PRIV_LOG_FED_SIGNING_SEED` + `PRIV_LOG_FED_AUDIENCE` are set (`server/src/fedIssuer.js`, ES256 via createECDH, `npm run fed-key`, public setup at `GET /api/fed-setup`); the seed is write-only and a test greps every answer for it.
- Web: the trace renders every log entry with `components/JsonTree.jsx` (iterative walker in `lib/jsonTree.js`, parsing in `lib/logEntry.js`); colours come from `--json-*` tokens in `tokens.css` mapped onto standalone-ui.css tokens; never `innerHTML`. Run progress is `components/Busy.jsx` + `App.jsx` (`busy` map, `epoch` ref cancels loops on Reset or a mode switch).
- Scorer is pinned against the capture with FIVE documented differences (`server/test/scorer.test.js`): the sample lines are excerpts. Do not widen that list to make a test pass; fix the scorer or document why. Heuristic: an OAuth-looking client id is `partial` for agent. Mutation tests remove lines and expect scores to drop.
- Real runs only MCP cases (tools/call, tools/list). A2A, LLM and intent need routes not measured here (UNVERIFIED): they are `not_runnable` (409) and use the paste box. Real tests use an in-process FAKE gateway and FAKE search only. Never put a live credential in a test, a doc or a commit.
- Web: `web/src/App.jsx` (shell-bar header, mode toggle, confirm gate, presenter mode `P`, theme picker, Reset), `components/` Run, Trace (marks via `lib/marks.js`), Scorecard (Markdown copy), Sinks, Diagram (`PatternDiagram` over `diagram-studio/1` data from `/api/diagram`), TalkTrack. Colours from tokens only (`standalone-ui.css` is vendored and pinned: `scripts/check-ui-standard.sh`). Log lines render as React text through `visible()`, never `dangerouslySetInnerHTML`.
- Content pack uses catalog `D999` (the family's "no row yet" placeholder; the schema requires one). `docs/shelf-entry.json` has no `catalogId` on purpose: no catalog row truly matches. Registering the port in demo-shelf-LAB `data/demos.json` and the shelf merge are owner steps.
