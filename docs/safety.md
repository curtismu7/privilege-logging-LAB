# Safety

- Loopback bind only (`PRIV_LOG_BIND` is the explicit opt-in the container uses); the compose file publishes `127.0.0.1:7801` only (a test pins it) and mounts nothing from the host. Host header must be a loopback name (or one in `LAB_ALLOWED_HOSTS`); writes must be same-origin.
- **Mock sends nothing.** The netguard blocks every non-loopback socket, DNS lookup, fetch and UDP send, with a self-test (run by doctor and health) and a test that runs all 17 cases against an app configured for Real and asserts zero attempts and zero requests at the configured fake servers.
- **Real contacts only the configured origins** (the gateway, plus the log sources you set: a `kubectl proxy` origin and/or a search origin). `realClient.js` is the only code that sends. It refuses any URL whose origin is not the gateway or the search endpoint before opening a socket; allows https (or http on loopback) only; refuses credentials in URLs; resolves host names itself and refuses private, link-local, metadata (169.254.x), CGNAT, multicast and reserved addresses (a mixed answer is refused), connecting to the address it checked; never follows a redirect (a 3xx is shown, its `Location` is never contacted); caps each request at 8 s and each response at 256 KB (reading stops at the cap); caps request bodies. The netguard allow-list is set to the two configured host names while Real is on and emptied when you switch back to Mock.
- **Confirm gate.** The first send in each browser tab needs the origins confirmed (`POST /api/confirm`, the gateway origin echoed back). Until then `POST /api/run` answers 412 and nothing is sent. Reset forgets the confirmation. Real is never on by default in Docker (`MODE=mock`).
- **The agent key is write-only.** It is read inside `config.js` from `~/Development/.env` / `STANDALONE_ENV` / the environment, handed to the Real client, and never returned by any API, never logged, and replaced by `***` in every raw request, response and error the client hands back. `GET /api/info` reports only that a key is configured. A test greps every API answer of a full Real run (including a gateway that echoes the Authorization header) for the key.
- **Pasted and returned log text is hostile data.** It is rendered as React text only (control and bidirectional characters shown as visible escapes), never as markup. The paste is capped at 200 KB and 500 lines of 4096 characters; the scorer reads it in one linear pass with `indexOf` and a key=value tokenizer, JSON is walked with an explicit stack (depth 5, 400 nodes), the few regexes run on values capped at 200 characters with no nested quantifiers. No `eval`, `Function` or `vm`.
- Writes are limited to `POST /api/mode|confirm|run|score|reset` with strict bodies (unknown keys refused, 300 KB limit). Nothing writes to a gateway's configuration: Real sends MCP calls and one read-only search.
- No identifiers from anywhere else: the capture is sanitised to placeholders and the validator rejects a non-reserved host or a real-looking UUID in it. Only `.example` / `.invalid` hosts ship. No tenant, credential or customer identifier ships.
- **Log retrieval is read-only and bounded.** The pod log is one GET (and, for a selector, one list GET), `redirect` never followed, a 1 MB cap (reading stops at it, newest lines kept via `tailLines`), 5000 lines kept of 4096 characters each, at most 200 shown, at most 3 pods; the page polls at most 120 times. Namespace, pod, container and selector are validated names (no path traversal, no shell characters) before they enter a URL.
- **Shown log lines are redacted** (Bearer tokens, JWTs, key/secret/password values) before they are scored, stored or sent to the page, including the raw bodies of the log-source hops; pasted lines get the same pass. The copy button runs a second client-side pass.
- **Per-case credentials are write-only**: `POST /api/bearer` stores one in memory for this tab, answers only `configured: true|false`, and the value is replaced by `***` in every raw request, response and error. `PRIV_LOG_BEARER_<CASEID>` is read only inside `config.js`.
- **The JSON viewer renders text only.** Values and keys are React text nodes (control and bidirectional characters shown as escapes), built by an iterative walker with depth 10, 1500 nodes, 200 children per node and 200 characters per string (20000 behind Show more); a hostile entry cannot hang the page or inject markup.
- **Not-yet-measured cases never show a result**: the validator rejects recorded lines, outcome or score on a `realOnly` case, and Mock refuses to run them.
